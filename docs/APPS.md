# Desktop, Android and iPhone apps

All three are the same web app wrapped in a native shell. Games, scores and settings are stored on the device.

| App | Folder / file | Built on this PC? | Tested |
|---|---|---|---|
| Windows desktop (portable) | `release/Quiz Show Studio-win32-x64/` | yes | launched, hosted, presentation window, security checks |
| Android | `release/QuizShowStudio.apk` | yes | installed on an Android 16 emulator, joined a desktop host over WebRTC, real touch buzz |
| iPhone / iPad | `ios/` (Xcode project) | **no, needs a Mac** | not built or run |

## Windows desktop (no install)

Run: double-click `Quiz Show Studio.exe` inside the folder. Nothing is installed or registered.

- **Everything lives in the folder.** Games, scores and settings are saved in `data/` next to the exe, so copying the whole folder (USB stick, another PC) moves everything. If the folder is read-only (for example under Program Files) it falls back to the normal profile folder.
- **Second monitor:** `Open presentation window` opens on the other display, full screen. F11 toggles full screen, Esc leaves it, Ctrl +/- zooms.
- **One copy at a time.** Starting a second copy just focuses the first.
- **Windows SmartScreen** may warn that the program is from an unknown publisher, because the exe is not code-signed (signing needs a paid certificate). Choose *More info > Run anyway*.
- Size is about 310 MB because it carries its own Chromium.

Rebuild after changing the code: `npm run package:win` (your `data` folder is kept). If a copy of the app is still running the folder is locked; close it, or build next to it with `npm run package:win -- --staging` (output in `release/staging/`; move the old `data` folder across after closing the old copy to keep your games). Try it without packaging: `npm run desktop`.

## Android

Install on a phone: copy `release/QuizShowStudio.apk` to the phone and open it. Android asks you to allow installs from that source (Settings > Apps > Special access > Install unknown apps). Play Protect may show a warning for apps not from the Play Store.

Rebuild: `npm run android:apk` (needs JDK 17+ and the Android SDK, found automatically in `%LOCALAPPDATA%\Android\Sdk`, or set `ANDROID_HOME`). The first build downloads Gradle.

That APK is signed with Android's *debug* key, which is fine for sideloading. For the Play Store you need your own signing key and an app bundle: open the `android/` folder in Android Studio, then *Build > Generate Signed App Bundle*. Keep the key file safe; losing it means you can never update the app.

## iPhone / iPad

Apple only lets Xcode build iOS apps, and Xcode only runs on a Mac, so this could not be built or tested here. The project is ready:

1. On a Mac with Xcode: copy this project folder, run `npm install`, then `npm run mobile:sync`.
2. `npx cap open ios`, select the *App* target > *Signing & Capabilities*, pick your Team.
3. Choose your iPhone (or a simulator) and press Run.

A free Apple ID installs on your own phone for 7 days at a time. TestFlight and the App Store need the paid Apple Developer Program (US$99/year). The bundle ID is `com.quizshowstudio.app`; change it in `capacitor.config.ts` before publishing, then run `npx cap sync`.

## Joining games from the apps

- **Players** open the app (or your website), tap **Join**, and type the 5-letter code.
- **QR code and link:** inside the desktop/phone apps the page address is private, so the QR code needs the web address of your hosted copy. Enter it once in **Settings > Connection > Your website address**. Without it the host screen just shows the room code.
- **Same Wi-Fi, no internet:** run a free signaling server on the host PC with `npx peerjs --port 9000 --path /`, then enter `<host PC address>:9000` in **Settings > Connection > Custom connection server** on the host. The QR code carries it to players. (The server is the `peer` package, already in this project's dev dependencies.) Windows may ask to allow it through the firewall.
- **Hosting from a phone** works, but there is no second-screen presentation window, no printing, and file export goes through the phone's share sheet.
- The Android and iOS projects allow plain `ws://` only so the optional LAN server above can work. The default public server uses encrypted connections.

## Regenerating icons and splash screens

`node scripts/make-icons.mjs` (Windows icon + 1024px art) and `node scripts/mobile-assets.mjs` (Android and iOS icons and splash screens). `npm run mobile:sync` runs the second one for you.

## Layout

    electron/main.cjs        desktop shell: app:// scheme, portable data folder, popup/second-monitor handling
    capacitor.config.ts      phone app settings
    android/  ios/           native projects (generated by Capacitor, then customised)
    scripts/package-win.mjs  portable Windows build
    scripts/build-apk.mjs    Android build
    scripts/make-icons.mjs, mobile-assets.mjs   original icon art, no image files needed
